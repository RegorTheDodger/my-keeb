# Journal Entry 1 — Planning

**Date:** August 17, 2026

## What I decided to build

The RegorBoard 6000 — a full-size mechanical keyboard with numpad, function row, arrow keys, and navigation cluster. 104 keys total. No RGB, no extras, just a clean and powerful full-size board with silent linear switches.

## Why this layout?

I want a keyboard that does everything. Full size means nothing is missing — I get the numpad for numbers, the function row for shortcuts, and arrow keys without having to hold anything. It's the most complete keyboard layout you can build and I wanted to go all out.

## Switch choice

Silent linear switches. Fast, smooth, and quiet. No clicky nonsense — just clean keypresses that don't annoy everyone around me.

## Tools I'll be using

- **KiCad** — for PCB schematic and layout
- **Onshape** — for designing the keyboard case
- **QMK** — for writing the firmware
- **GitHub** — to track everything

## Next steps

- Install KiCad and start the schematic
- Map out the full key matrix (104 keys)
- Choose the microcontroller

## What I learned

Planning a full-size keyboard is more complex than it looks. A 104-key matrix needs careful planning — you can't just wire everything in a straight line. The switch matrix has to be laid out in rows and columns efficiently so the microcontroller can scan it fast enough. Already learning a ton before even opening KiCad.
